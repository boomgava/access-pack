# Пакет доступов

Собирает на каждого сотрудника ZIP-архив под своим паролем: PDF с доступами и короткой инструкцией плюс общие вложения (RDP, инструкции, ПО). Пароли архивов — на экране результата и в `Пароли.txt`.

## Как пользоваться

1. ⚙ Настройки → проверить справочник систем (адрес IntraService, шаги), загрузить логотипы и контакты поддержки, выбрать библиотеку вложений.
2. Добавить сотрудников: ФИО и готовые учётки (система, логин, пароль). Для домена достаточно `ivanov.i` — префикс `company\` подставится сам.
3. Отметить вложения; разовые файлы — перетащить в блок «Разовые файлы».
4. «Собрать» → архивы и `Пароли.txt` в папке `Доступы_ГГГГ-ММ-ДД_ЧЧ-ММ`.

«Только памятка» рядом с кнопкой сборки печатает одни PDF с доступами, без архивов и паролей, в папку `Памятки_ГГГГ-ММ-ДД_ЧЧ-ММ`.

Логины и пароли учёток нигде не сохраняются — только внутри зашифрованных архивов.

**Отправка писем.** Галочка «Отправить письма» в нижней панели включает поле почты у каждого сотрудника. После сборки адреса видны в таблице результата — их можно поправить перед отправкой. Программа отправляет архивы сама по SMTP: сервер, логин, тема, шаблон письма и копия (Cc) задаются в Настройках → «Почта», пароль хранится в ключнице системы (Keychain, DPAPI), а не в `settings.json`. В шаблоне работают подстановки `{ФИО}`, `{Имя}`, `{Фамилия}`, `{Архив}`; пароль от архива в письмо не подставляется — его передают отдельно. Кнопка «Проверить подключение» доходит до авторизации и ничего не отправляет.

**История.** Кнопка «История» показывает выданные архивы: когда, кому, пароль архива и его состав — учётки с логинами и вложения. Пароли учёток туда не попадают. Записи лежат в `history.json` в папке данных программы открытым текстом, как `Пароли.txt`, и удаляются через 90 дней (поле `historyDays` в настройках).

**Внешний вид.** Настройки → «Внешний вид»: тема (как в системе, светлая, тёмная, розовая), картинка в углу окна и своя картинка на фоне с ползунком затемнения. Встроенные картинки — аниме-арт с Викисклада под свободными лицензиями; авторы и лицензии перечислены в `src/assets/themes/ATTRIBUTION.md` и показываются в настройках.

**Шифрование.** ZipCrypto открывает Проводник Windows без программ. Но если в архиве лежит общедоступный файл (например, установщик), архив вскрывается атакой по известному файлу — для таких случаев выбирайте AES-256 (открывается 7-Zip).

**Перенос настроек.** Настройки → «Перенос настроек»: «Экспортировать…» сохраняет файл JSON с системами, профилями, логотипами, шаблоном письма и оформлением. Пароль почты в файл не попадает — он лежит в ключнице системы. При импорте можно выбрать, что принять: только общее (системы, профили, шаблон, вид — свои папки и свои адреса почты остаются) или всё из файла, включая папки и адреса, для переноса на новый компьютер.

**Где лежат настройки.** `~/Library/Application Support/AccessPack/` на macOS, `%APPDATA%\AccessPack\` на Windows: `settings.json`, `history.json`, зашифрованный `secrets.bin` и папки `logos`, `backgrounds`. Обновление программы эту папку не трогает, новые поля добавляются миграцией.

**Обновления.** Программа смотрит релизы этого репозитория и показывает полосу «Вышла версия X» со ссылкой на страницу загрузки. Сама себя она не обновляет и ничего не скачивает: на macOS автообновление требует подписи Apple Developer ID. Проверку можно отключить в Настройках → «Обновления».

## Первый запуск

- **Mac:** открыть `.dmg`, перетащить AccessPack в «Программы», первый раз — ПКМ → «Открыть».
- **Windows:** `AccessPack-…-portable.exe` запускается без установки и прав администратора; SmartScreen → «Подробнее» → «Выполнить в любом случае».

## Сборка релиза

Сборки собирает GitHub Actions по тегу:

```bash
npm version minor        # поднимет версию в package.json и создаст тег
git push && git push --tags
```

## Разработка

```bash
npm install
npm test               # юнит- и сквозные тесты (нужны python3, unzip; для AES — brew install sevenzip)
npm start              # запуск
npm run demo           # запуск с примером пачки
npm run smoke:pdf      # образцы PDF во временную папку
npm run dist:mac       # dist/*.dmg
npm run dist:win       # dist/*-portable.exe
```
